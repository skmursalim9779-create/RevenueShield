# Python 3.14 Update

Revenue Shield was updated to use a modern Python 3.14-compatible dependency set.

- Streamlit 1.64.0
- pandas 3.0.6
- NumPy 2.5.3
- scikit-learn 1.8.0
- Plotly 7.0.0
- Requests 2.34.2

The existing application features and original code were retained. The update focuses
on the runtime/dependency layer and adds a Python-version guard.
